# 历史设计记录（非强制工作流）

此目录保留原项目和本 Fork 的历史设计/测试记录，供需要时参考。旧文档中提到的功能分支、PR、预览包、release 标签、先写规格再编码、所有语言必须同步修改、格式检查及上游审批流程 **均不适用于个人 Fork 的日常开发**。

个人 Fork 直接在 `main` 修改；`personal-fast-apk.yml` 自动构建并发布。是否编写方案、补测试或运行完整验证，按改动的实际风险与使用者明确要求决定，而不是按历史模板执行。旧历史记录不删除，避免丢失技术背景与问题复盘。

开发说明以当前源代码、[README](../../README.md) 和 [实际发布流程](../releasing.md) 为准。保留许可证、凭据保护、安装签名和更新完整性等必要安全机制。
